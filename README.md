# SmartNote AI — تبدیل عکس تخته به جزوه

این پروژه عکس‌های تخته کلاس را با مدل بینایی OpenAI بررسی می‌کند و جزوه فارسی ساختارمند تحویل می‌دهد.

## پیش‌نیازها
- Python 3.10 یا جدیدتر
- Node.js نسخه LTS
- کلید API از OpenAI Platform (هزینه API جدا از اشتراک ChatGPT محاسبه می‌شود)

## ۱) اجرای بک‌اند
در VS Code یک ترمینال باز کن و وارد پوشه `backend` شو:

```powershell
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

کلید API را در همان ترمینال PowerShell تنظیم کن. به‌جای متن نمونه، کلید واقعی خودت را قرار بده:

```powershell
$env:OPENAI_API_KEY="کلید-واقعی-تو"
```

مدل پیش‌فرض `gpt-6.1-sol` با تلاش استدلالی بالا است. برای تغییر مدل می‌توانی از متغیر `OPENAI_MODEL` استفاده کنی. کلید API را هرگز داخل HTML، React، GitHub یا پیام عمومی قرار نده.

سرور را اجرا کن:

```powershell
uvicorn main:app --reload --port 8000
```

برای بررسی اجرا، این آدرس را باز کن: `http://127.0.0.1:8000/health` باید پاسخ `{"status":"ok","service":"SmartNote AI"}` ببینی.

## ۲) اجرای سایت
یک ترمینال دوم در VS Code باز کن و وارد پوشه `frontend` شو:

```powershell
cd frontend
npm install
npm run dev
```

آدرس Vite (معمولاً `http://localhost:5173`) را در مرورگر باز کن.

## ۳) گرفتن جزوه
1. یک یا چند عکس واضح از تخته انتخاب کن؛ ترتیب انتخاب عکس‌ها را مطابق ترتیب جزوه نگه دار.
2. روی «تولید جزوه کامل» بزن.
3. بعد از آماده شدن جزوه، برای ذخیره PDF گزینه «چاپ / ذخیره به صورت PDF» را بزن و در پنجره چاپ، `Save as PDF` را انتخاب کن.

## محدودیت‌ها و دقت
- حداکثر ۸ تصویر JPG/PNG/WEBP، هرکدام حداکثر ۱۰ مگابایت.
- تصاویر با جزئیات اصلی برای خواندن نوشته‌های ریز ارسال می‌شوند.
- مدل ممکن است دست‌خط ناخوانا، نوشته‌های خیلی ریز، عکس تار یا فرمول پیچیده را اشتباه بخواند. بخش‌های نامطمئن باید در خروجی علامت‌گذاری شوند و قبل از استفاده با عکس اصلی تطبیق داده شوند.
- کیفیت عکس روی دقت خروجی اثر زیادی دارد: عکس صاف، روشن، بدون لرزش و با کل تخته در کادر بگیر.
- ارسال تصاویر به OpenAI API برای پردازش انجام می‌شود و هزینه بر اساس مدل و میزان استفاده محاسبه می‌شود.
